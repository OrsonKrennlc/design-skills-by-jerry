首个版本，提供三个可独立安装的设计技能。按需要选择一个即可。

- **tvos-interaction-spec**：电视页面交互文档、焦点与遥控器六键规则。
- **web-prototype-design**：Web / 后台页面、关键状态与按需演示的交互原型。
- **web-interaction-spec**：依据 PRD 与 Figma 设计稿撰写 Web 交互说明。

包含 ChatGPT、Claude、Antigravity、WorkBuddy、TRAE 安装教程，以及 Figma 官方插件 / MCP 与 Figwright 连接方法。

### 下载哪一个

- `<skill-name>.zip`：标准包，内含同名完整技能文件夹，适合 Claude 等导入器或解压安装。
- `<skill-name>-flat.zip`：兼容包，根层直接包含 SKILL.md，适合明确要求该结构的导入器。
- `SHA256SUMS`：本 Release 六个安装包的 SHA-256 校验值。

两种包内容相同，只需选一种；不需要把全部技能安装一遍。GitHub 自动生成的 Source code ZIP 是整个仓库，不是单个技能安装包。
