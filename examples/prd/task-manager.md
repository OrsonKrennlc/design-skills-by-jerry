# 轻量任务管理后台 PRD

版本：0.1，设计测试用。本文中的人员和任务均为虚构数据。

## 1. 产品用途

给一个小团队记录任务、分配负责人，并查看完成情况。使用者是团队管理员，本次不区分用户角色和权限。

产品为桌面 Web 后台，UI 使用中文，包含“概览”和“任务管理”两个模块。没有需求原型，页面布局由设计方案确定。

## 2. 本次范围

- 概览：查看任务数量，跳转到对应状态的任务列表。
- 任务管理：搜索、筛选、新建、编辑和删除任务。

本次不做登录、成员管理、分页、批量操作、通知和导出，也不连接真实后端。

## 3. 全局规则

负责人固定为张晨、李琳、王敏，在任务表单中单选。

任务有三个状态：待开始、进行中、已完成。编辑时可以在三个状态之间任意切换。

概览和任务管理使用同一份任务数据。新增、修改状态或删除任务后，两处数据都要更新，不能出现数量对不上的情况。

通过模块导航进入“任务管理”时，默认显示全部任务，搜索框为空。列表按创建先后倒序排列，新任务放在最上方；编辑不会改变任务顺序。

## 4. 概览

展示四个数量：全部任务、待开始、进行中、已完成。全部任务数应等于后三项之和。

点击“全部任务”进入任务管理，显示全部任务；点击某个状态的数量，进入任务管理并选中对应的状态筛选。通过这些入口进入时，搜索框都为空。

没有任何任务时，四个数量均为 0，仍可点击进入任务管理。

## 5. 任务管理

### 5.1 列表

页面提供任务名称搜索、状态筛选和“新建任务”按钮。

列表列出任务编号、任务名称、负责人、状态和操作。每条任务提供“编辑”和“删除”，不支持直接在表格内修改。

搜索只匹配任务名称，按包含关键词查找。点击“搜索”或按 Enter 后生效；搜索前去掉关键词首尾空格。空关键词表示不限制名称。

状态筛选包含全部、待开始、进行中、已完成，选择后立即生效。名称搜索与状态筛选同时满足时，任务才显示。

没有任何任务时，显示“暂无任务”，并提供“新建任务”按钮。存在任务但当前搜索或筛选没有结果时，显示“没有符合条件的任务”，并提供“清空条件”，点击后清空搜索、恢复全部状态。

### 5.2 新建任务

点击“新建任务”打开弹窗，包含以下字段：

| 字段 | 规则 |
| --- | --- |
| 任务名称 | 必填，去除首尾空格后为 1 至 40 个字符，允许重名 |
| 负责人 | 必填，单选张晨、李琳或王敏，默认未选 |
| 状态 | 必填，默认待开始，可选择三个状态中的任意一个 |
| 备注 | 选填，最多 200 个字符 |

点击“保存”时校验。名称为空时提示“请输入任务名称”；名称超过上限时提示“任务名称最多 40 个字符”；未选负责人时提示“请选择负责人”；备注超过上限时提示“备注最多 200 个字符”。错误显示在对应字段旁，弹窗保持打开，其他已填内容保留。

保存成功后关闭弹窗，显示 toast“任务已创建”。列表清空搜索、恢复全部状态，新任务显示在第一行，概览数量同步更新。

任务编号由系统生成，初始数据之后的新任务依次使用 T006、T007，以此类推。已删除的编号不再使用，用户不需要填写编号。

点击“取消”或右上角关闭按钮，直接放弃本次输入并关闭弹窗，不额外弹出确认，也不改变列表条件和任务数据。

### 5.3 编辑任务

点击行内“编辑”打开与新建相同的弹窗，带入当前任务信息，标题为“编辑任务”。字段规则与新建一致。

保存成功后关闭弹窗，显示 toast“任务已保存”，列表保留原有搜索和筛选条件。若修改后的任务不再满足当前条件，它从当前列表中消失；必要时显示无结果状态。概览数量同步更新。

取消或关闭弹窗时，放弃未保存的修改，列表和概览都不变化。

### 5.4 删除任务

点击“删除”后弹出确认框，标题为“删除任务”，正文为“确定删除「任务名称」吗？删除后无法恢复。”其中任务名称替换为当前记录的名称。

确认按钮为“删除”，取消按钮为“取消”。取消或关闭确认框后不做修改。

确认删除后关闭确认框，显示 toast“任务已删除”。列表保留原有搜索和筛选条件，概览数量同步更新。删除最后一条任务后，列表显示“暂无任务”。

## 7. 检查示例

1. 从概览点击“待开始”，应进入只显示 T004 和 T001 的列表，搜索框为空。
2. 搜索“表单”且状态为全部时，只显示 T003；再筛选待开始时，应显示无结果状态。
3. 新建一个默认状态的任务后，全部任务变为 6、待开始变为 3。新任务编号为 T006，显示在列表第一行。
4. 将 T004 从待开始改为已完成，原始数据中的待开始变为 1、已完成变为 2，全部任务仍为 5。若当时筛选了待开始，保存后 T004 不再显示。
5. 删除 T003 后，原始数据中的全部任务变为 4、已完成变为 0。
6. 编辑任务但取消，或打开删除确认框后取消，任务内容和概览数量都不变化。

以上示例分别从初始测试数据开始，不累计前一项的操作结果。
